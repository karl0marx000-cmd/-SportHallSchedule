# Расписание спортивного зала — Android-приложение

Нативное Android-приложение на Kotlin, Jetpack Compose и Room (локальная SQLite-база). Интерфейс выполнен в спокойной серо-зелёной гамме.

## Функции
- Вход по логину и паролю; пароли хранятся в виде PBKDF2-HMAC-SHA256 хеша с уникальной солью.
- Роли: администратор, тренер и пользователь. Роли руководителя в приложении нет.
- Администратор создаёт, редактирует и отменяет занятия; управляет справочниками тренеров, видов тренировок и залов (добавление, изменение, деактивация). При добавлении тренера задаются индивидуальные логин и пароль.
- У каждого тренера отдельная учётная запись, связанная с конкретным trainerId. Тренер видит только занятия, назначенные ему; не может изменять расписание или справочники.
- Пользователь видит общее расписание, но не административные элементы.
- Фильтрация по диапазону дат и поиск по тренеру, виду тренировки и залу.
- Проверки формата/существования даты, времени начала и окончания, конфликтов тренера и зала.
- Сохранение в локальную базу Room между запусками; аудит создания, изменения и отмены занятий.
- При первом запуске добавляются демонстрационные справочники и несколько помеченных демонстрационных занятий. Их можно отменить.

## Учётные записи для демонстрации (чистая установка)
- Администратор: `admin` / `admin123`
- Анна Смирнова: `anna` / `anna123`
- Максим Орлов: `maxim` / `maxim123`
- Елена Волкова: `elena` / `elena123`
- Пользователь: `guest` / `guest123`

При добавлении нового тренера администратор задаёт его логин и пароль в карточке тренера. Изменить логин можно через редактирование тренера; чтобы оставить прежний пароль, поле нового пароля нужно оставить пустым. Пароли хранятся в виде PBKDF2-HMAC-SHA256-хешей с отдельной солью. Демо-пароли предназначены только для учебной демонстрации. Данные хранятся локально на устройстве, серверной синхронизации нет.

## Открытие проекта
1. Распакуйте архив в короткий путь без кириллицы, например `C:\Projects\SportHallSchedule_Pro`.
2. В Android Studio выберите **File → Open** и откройте корневую папку с `settings.gradle.kts`.
3. Дождитесь Gradle Sync. Нужны Android SDK Platform 35 и JDK 17; Android Studio обычно устанавливает/выбирает их через SDK Manager.
4. Подключите телефон с включённой отладкой по USB или создайте эмулятор и нажмите Run.
